# 设计

## 架构

```
Flutter UI（Android / Windows；macOS 本机验证）
  转换页 ── convertDicomPackageInBackground（isolate）
              archive → discover → window → encode → package
  预览器 ── 片号滑条 + 缩放（不回读 DICOM；GIF 按帧解码）
  历史页 ── JobStore（jobs.json）+ 本机结果文件
```

引擎语义对齐 DicomFlow `.ai/04-engine.md`，**运行时独立**（不嵌 Python、不调线上 API）。rar / 7z 开箱可解：桌面用包内 7-Zip，Android 用纯 Dart `koni_archive`，不要求用户再装解压软件。

## 平台

| 平台 | 角色 |
|------|------|
| Android | P0：选文件、转换、预览、系统分享 / 保存 |
| Windows | P0：选文件、转换、预览、打开文件夹 |
| macOS | 本机验证与打包（同 Flutter 代码）；非商店目标 |
| 其他 | 同架构预留 |

桌面（macOS / Windows）支持拖放 zip/rar/7z；也可用系统文件选择器。默认窗口约 1280×840（macOS 最小 1024×720）。

## UI 契约

品牌色（`theme.dart`）：primary `#2563eb`，accent `#f97316`。  
**布局与交互按原生 App，不照搬网页三步营销长页。**

启动：冷启动展示品牌启动页约 1.6s（可测 `DicomFlowApp(showSplash: false)` 跳过）。

| 宽度 | 导航 | 转换页 |
|------|------|--------|
| &lt; 720 | 底栏「转换 \| 历史 \| 关于」 | 虚线投递区选文件；选后格式卡片 + 清晰度/帧率芯片；完成后全宽预览 |
| ≥ 720 | 左侧 NavigationRail（品牌标） | 拖放打开；`⌘O` / `Ctrl+O`；完成后左侧预览、右侧文件与操作 |

信息结构：

1. 转换：打开压缩包 → 格式/清晰度/fps/合并 → 预览与分享；空状态有「选压缩包 → 本机转换 → 预览导出」示意
2. 预览器：画面中央播放；右上角放大/缩小；片号滑条；捏合 / 滚轮仍可用。GIF 在 isolate 解码，切文件不卡住 UI
3. 结果：操作条固定（分享、导出到文件夹、打开/保存）；文件列表单独滚动。窄屏横向序列条
4. 「再转一个」清空已选文件并回到转换空状态；顶栏 × 关闭结果页（同一动作，不在按钮旁再放 ×）
5. 导出：系统目录选择器，只写入一个打包 zip，文件名为 `{源文件名}_{yyyyMMdd_HHmmss}.zip`
6. 历史：ListTile 显示源文件名与日期；顶栏卡片显示当前保留天数（橙色警示图标，与蓝色记录项区分），点进设置页更改。详情页桌面右侧文件列表通栏滚动；窄屏预览与文件列表按 3:2 分高，不再锁死两行
7. 设置：独立页配置历史保留 1天 / 7天 / 30天；点选项不立刻生效，保存后才写入。缩短且会删文件时必须确认
8. 关于：简介、GitHub 作者 `@AlexWuYh`（头像为 GitHub 主页照片，打包进安装包，可打开主页）、开源链接、许可；可进入设置。桌面端居中双栏等宽卡片；窄屏单列滚动
9. 任务落盘 application support 下 `jobs.json`；保留天数在 `settings.json`

## 明确不做的 UI

访问密码、人机验证、上传到服务器、诊断测量工具条、网页极光背景与三步营销卡。
